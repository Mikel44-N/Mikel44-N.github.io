DATA ANALYTICS & AUTOMATION PROJECT

Automated U.S. EV Registration Data Processing Workflow

An end-to-end workflow that automates the retrieval, cleaning, validation, processing, and analysis of U.S. electric vehicle registration data, with outputs prepared for Power BI reporting.

Project Overview

The objective was to connect data processing and reporting tasks into a repeatable workflow while introducing validation safeguards before production data is refreshed.

Input

EV registration CSV attachment retrieved from Outlook.

Processing

Python data cleaning, MySQL staging, validation, and SQL analysis.

Reporting

Ten analytical CSV outputs prepared for Power BI reporting.

How the Workflow Works

The workflow connects desktop automation, Python processing, database operations, SQL analysis, and reporting.

  1. Retrieve the source file: Power Automate Desktop retrieves the CSV attachment from Outlook.
  2. Clean and validate: Python processes the incoming data and checks that it meets the expected data requirements.
  3. Load to staging: The cleaned records are loaded into a MySQL staging table.
  4. Protect the production refresh: Validation checks determine whether the staged data can proceed to the production-table refresh.
  5. Run SQL analysis: SQL queries generate analytical results from the processed data.
  6. Prepare reporting outputs: Ten CSV result files are exported for use in Power BI.

Challenges & Lessons Learned

  • Database configuration: Correct credential and connection settings are essential for reliable database operations.
  • Debugging: Making execution results and error messages visible helps identify configuration and runtime problems.
  • Data validation: Automated workflows need checks to detect invalid data before it reaches downstream reporting.
  • Controlled updates: Production data should only be refreshed when the required validation checks pass.
